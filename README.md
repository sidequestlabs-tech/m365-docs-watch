# m365-docs-watch

Watches Microsoft Learn pages that matter for Microsoft 365 forensics and incident response (audit logs, eDiscovery, Insider Risk, Defender, Entra, Sentinel, endpoint), plus the Microsoft 365 Roadmap feed. Sends a phone push via ntfy when something forensically important changes (retention, limits, licensing, deprecations, new tables/operations), and a Monday digest for everything else. Design: `docs/notifier-design.md`. Setup: Task 9 of `docs/superpowers/plans/2026-11-15-notifier.md`.

Snapshots in `snapshots/` are copies of Microsoft Learn documentation, © Microsoft, licensed CC BY 4.0 (https://creativecommons.org/licenses/by/4.0/).
