## M365 Roadmap

### [M365 Roadmap: Microsoft Purview: Information Protection - Improved sensitive information types](https://www.microsoft.com/microsoft-365/roadmap?id=579195)
**New roadmap item: improved out-of-box SITs, preview Jan CY2027, GA Mar CY2027**

- New: Improved Microsoft out-of-the-box sensitive information types (SITs) to identify sensitive data more precisely and reliably. GA date: March CY2027 Preview date: January CY2027

### [M365 Roadmap: Microsoft Purview: Endpoint Data Loss Prevention-Extend Purview data security to the network layer through integration with Azure Firewall](https://www.microsoft.com/microsoft-365/roadmap?id=577828)
**New roadmap item: Purview DLP network-layer enforcement via Azure Firewall, preview Nov CY2026**

- New: Microsoft Purview extends data security controls to the network layer through integration with Azure Firewall, helping organizations detect and protect sensitive data in supported network traffic, including text, files, and AI interactions. Organizations are able to enforce DLP policies on traffic from servers, virtual machines, and other endpoints, including traffic generated by background services and automated workloads. ### [M365 Roadmap: Microsoft Purview: Information Protection-Sensitivity label inheritance for Teams meeting artifacts](https://www.microsoft.com/microsoft-365/roadmap?id=581739)
**Roadmap item added: Teams meeting artifacts inherit sensitivity labels, GA December CY2026**

- New: Teams meeting artifacts, including recordings, transcripts, and Loop notes, can now be configured to automatically inherit the sensitivity label from the meeting. This ensures content generated during meetings is consistently protected without requiring manual labeling, reducing risk and simplifying protection at scale. GA date: December CY2026
